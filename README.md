# ✅ لیست کارها (Todo App)

یک وب‌اپلیکیشن سادهٔ مدیریت کارهای روزانه — فارسی، راست‌چین و بهینه‌شده برای iPad و موبایل.

## امکانات

- ➕ افزودن کار جدید
- ✓ علامت‌گذاری کارها به‌عنوان انجام‌شده
- 🗑 حذف کارها
- 🔍 فیلتر: همه / در انتظار / انجام‌شده
- 💾 ذخیرهٔ خودکار در مرورگر (localStorage) — بدون نیاز به سرور
- 🌙 پشتیبانی از حالت تاریک (بر اساس تنظیمات دستگاه)
- 🔢 نمایش اعداد فارسی

## اجرا

هیچ نصب یا build لازم نیست! فقط فایل `index.html` را در مرورگر باز کنید.

برای اجرای محلی با سرور:

```bash
python3 -m http.server 8000
```

سپس به آدرس `http://localhost:8000` بروید.

## انتشار با GitHub Pages

۱. به Settings → Pages در مخزن گیت‌هاب بروید
۲. Source را روی شاخهٔ مورد نظر تنظیم کنید
۳. اپ شما روی آدرس `https://<username>.github.io/<repo>/` در دسترس خواهد بود
